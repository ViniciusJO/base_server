# base_server

Basic configurations for:

- [neovim](https://neovim.io/)
- [tmux](https://github.com/tmux/tmux)
- [zsh](https://www.zsh.org/)

The script `install.sh` puts the `nvim` and `tmux` configs in the proper user directories. The `zsh` is configured globally. The script do not need any argument and can be called:

```sh
./install.sh
```
